=== SHEET: Clone_API_Standards (dims A1:C13) ===
Area	Production Decision	Design
Base URL	Versioned REST API	/api/v1
Authentication	Identity-provider login + server session	Agent authenticates through external identity layer; clone issues HttpOnly/Secure session cookie and CSRF token after callback.
Agent identity	Email is login identity	Map authenticated external subject/email to HD_AGENT_MASTER; do not store plaintext passwords in HD_AGENT_MASTER.
Authorization	RBAC + department/team scope	Role/Profile + department/team membership determines accessible modules and records.
Tenant isolation	Mandatory org context	Every business query is scoped by Org_Id from authenticated session, never trusted from request body.
Pagination	Cursor or offset contract	Default limit 50; maximum 100; return nextCursor/hasMore. Internally support offset for compatibility.
Errors	Normalized JSON envelope	{code,message,details,traceId} with HTTP status aligned to semantics.
Idempotency	Write endpoints	POST operations that can create duplicate side effects accept Idempotency-Key.
Concurrency	Optimistic locking	PATCH supports If-Match/version field for ticket/dashboard mutations.
Audit	Security + business audit	Login/security events in HD_AUTH_LOGIN_EVENT; ticket changes in HD_TICKET_HISTORY.
Analytics	Query contract	Dashboard widgets store query JSON/version and execute through a controlled analytics service; never accept arbitrary SQL from clients.
Caching	Server-side	Dashboard widget results may be cached using component Cache_TTL_Sec; invalidate on relevant data changes where feasible.
